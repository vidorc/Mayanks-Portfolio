## Highlights

- **Live demo simulations** — five fully-coded agent simulations (LeadPulse, MediFlow, TrackMind, OrderSync, FieldOps) running as WhatsApp-style chat and live operations dashboards. Step through each one with the button, `Space`, or `Esc`.
- **Cinematic hero** — interactive particle field, custom cursor, a looping LangGraph agent terminal, typewriter tech stack, and count-up stats.
- **Scroll choreography** — IntersectionObserver reveals, an assembling 4-layer architecture visualization, and a draw-in process flow.
- **Real engineering depth** — autonomous systems, active hackathon builds, ML/backend systems, experience, and an interactive tech-stack map with "Used in" tooltips.

## Tech

Pure **HTML + CSS + vanilla JavaScript** in one file. No frameworks, no build step, no JS dependencies. Google Fonts (`Syne`, `Plus Jakarta Sans`, `JetBrains Mono`) loaded via `<link>`.

- GPU-accelerated transforms & opacity only
- `IntersectionObserver` for all scroll animations
- `requestAnimationFrame` for the particle canvas
- Full `prefers-reduced-motion` support
- Keyboard-navigable, ARIA-labelled, focus-trapped modals
- Responsive: desktop → 1024 → 768 → 480

## Run locally

The site works opened directly from the filesystem — just double-click `index.html`, or:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deploy

**GitHub Pages**
Enable Pages in repo **Settings → Pages**, source: `main` branch, root. Live in ~60s.

**Netlify Drop**
Drag `index.html` onto [netlify.com/drop](https://app.netlify.com/drop).
