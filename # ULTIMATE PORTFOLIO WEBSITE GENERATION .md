## ANIMATION SYSTEM

### Layer 1: Background — Particle Field
Full-viewport canvas behind all content.
- 80 particles, size 1–2px, color: rgba(0,214,143,0.15) to rgba(77,159,255,0.1)
- Particles drift slowly (velocity ±0.3px/frame)
- On mouse move within 120px: particles gently repel (not aggressively)
- Particles connect with lines when within 80px: opacity proportional to distance
- Runs continuously but never distracts from content

### Layer 2: Custom Cursor
Replace default cursor with:
- Outer ring: 28px circle, border: 1.5px solid rgba(0,214,143,0.6), transitions position with 6-frame lag (smooth follow)
- Inner dot: 4px filled circle, color: #00d68f, follows cursor exactly
- On hover over clickable element: outer ring scales to 2x, fills with rgba(0,214,143,0.1)
- On hover over `.demo-btn` or `.hero-cta`: outer ring morphs to pill shape, turns green
- Cursor hides on mobile/touch

### Layer 3: Loading Screen
Full-viewport overlay, background: var(--bg).
- Center: Logo mark (stylized "M" or just "MS" in Syne 800)
- Below logo: horizontal progress bar, 280px wide, fills over 1.8 seconds
- Bar fill: animated gradient from --green to --blue
- Progress percentage counter in JetBrains Mono next to bar
- On complete: overlay fades up and out (translateY(-100%) + opacity 0) over 0.6s
- Page content fades in as loader exits

### Layer 4: Hero Animations
- Text lines animate in with stagger: each word/line slides up from 40px below + fade in
- Delay: 0.1s between each element after loader completes
- Tech stack line: each item types in one by one (typewriter effect), with cursor blinking between items
- Stats: count up from 0 on first viewport enter, using easeOutExpo curve

### Layer 5: Scroll Animations
All content sections use IntersectionObserver with threshold: 0.08
- Default entry: `opacity: 0 → 1` + `translateY(28px → 0)` over 0.65s ease
- Cards stagger: 80ms delay between each card in a grid
- Section labels: slide in from left (translateX(-20px))
- Headings: fade up
- NO jarring or bouncy animations — everything is smooth and premium

### Layer 6: Card Interactions
All project/system cards have:
- Hover: translateY(-4px) + border-color brightens + box-shadow deepens
- Hover: subtle inner glow appears at top of card (gradient overlay)
- 3D tilt effect on mouse move within card: rotate3d based on mouse position, max ±8deg
- Transition: all 0.3s cubic-bezier(0.23, 1, 0.32, 1)

### Layer 7: Magnetic Buttons
All CTA buttons (primary/secondary) have magnetic effect:
- When mouse within 80px of button: button translates toward cursor (max 8px)
- Creates "magnetic pull" feeling
- On click: brief scale-down 0.97, then spring back

### Layer 8: Demo Modal Animations
- Open: overlay fades in (opacity 0→1, 0.25s), modal box slides up from bottom (translateY(40px→0), 0.35s cubic-bezier(0.34, 1.56, 0.64, 1))
- Close: reverse
- Each chat message in demo: slides in from left (incoming) or right (outgoing)
- System event messages: fade in with slight scale (0.95→1)
- Step transitions: smooth highlight sweep animation
